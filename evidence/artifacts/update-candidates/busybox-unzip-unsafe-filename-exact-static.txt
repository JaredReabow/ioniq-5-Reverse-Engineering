[applicability result]
For this caller, zaccept contains literal patterns "AppUpgrade" and
".lge.upgrade.xml". With fnmatch flags zero and no wildcard metacharacters in
either pattern, a member containing an absolute prefix, a parent-directory
prefix, an added path component, or a trailing traversal component does not
match and is skipped before any output-path operation. Examples of rejected
shape classes include /AppUpgrade, ../AppUpgrade, x/AppUpgrade, and
AppUpgrade/../x. These are shape explanations, not test archives.

An embedded NUL is interpreted by both fnmatch and later path operations as the
same C-string terminator. A member whose visible prefix is exactly AppUpgrade
therefore targets the literal AppUpgrade output name; bytes after the NUL do not
become a separate traversal suffix in these calls.

Conclusion: commit 8c06bc6ba's unsafe-prefix defect is present in the stock
BusyBox generation, but the exact AppScomoDM command's literal inclusion filter
blocks traversal-shaped member names before output. It is not a supported
path-traversal finding for this route.
