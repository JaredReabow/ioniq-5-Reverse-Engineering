# Exact decompilation of 0x29ad2 establishes these ordered conditions before
# its dword count is returned to 0x28b46:
#
#   encoded_count != 0
#   encoded_count < 0x80
#   encoded_bytes = (encoded_count + 1) * 4
#   encoded_bytes <= (header_length & 0x1ff)
#   encoded_bytes <= 0x1fc destination capacity
#   first encoded type == 1
#   first encoded type <= encoded_count
#   nested_count <= encoded_count
#   nested_count == 1
#   nested end <= encoded end
#   nested end == encoded end
#

# parse subtracts the consumed dword count from the ordinary payload length.
# The ordinary payload is still received through a zeroed 0x1fc-byte local
# destination before message-capacity comparisons and process-buffer copying.

## Boundary

These excerpts prove exact differences between signed TXE 3.1.50.2222 and
signed later TXE 3.1.94.3086. They do not prove that any changed condition is
the fix for CVE-2018-12147. Version 3.1.94 is not the first-fixed 3.1.55 build,
and the changed control geometry plus new extension parser may include ordinary
protocol evolution. No HECI request was generated or transmitted.
